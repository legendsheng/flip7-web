# 🃏 Flip 7 — Web 网页版 (支持多人联机 & 本地同屏对战)

风靡全球的极限运气博弈卡牌游戏 **Flip 7** 的现代化 Web 实现。
支持**全中文 / 英文**双语一键切换，支持**多玩家在线联机**（局域网/互联网）与**本地同屏多人轮流对战 (Pass & Play)**，内置智能 AI 机器人，实时计算爆牌概率，提供豪华赌桌拟真质感与 Web Audio 合成音效，**零外部依赖**！

---

## 🌟 核心特性亮点 (Key Features)

1. **🌐 中英双语一键切换 (Bilingual Support)**
   - 界面右上角提供 `🌐 中文 / English` 切换按钮，游戏规则、卡牌名称、功能卡说明、实时战报及结算界面全量本地化。
   - 自动记忆语言偏好设置。

2. **👥 本地同屏多人对战 (Local Pass & Play Mode)**
   - **单设备多人畅玩**：支持 2 ~ 8 名玩家在同一台电脑、手机或平板上轮流操作。
   - **混合对战**：可自由添加真人玩家或 AI 机器人（例如 2 人好友 + 2 个 AI 机器人）。
   - **轮流通告**：每轮行动清晰提示“👉 请将设备交给 [玩家]”，并配备免爆护盾、冰冻对手、强迫连翻三张等全部原版玩法。
   - **完全离线可用**：本地模式纯前端运行，无需联网亦可随时开局。

3. **🎨 5 种个性化主题风格一键切换 (Multiple Aesthetics / Themes)**
   - 点击右上角【🎨 主题风格】按钮，随时在不同视觉氛围之间一键切换：
     - **🎰 经典绿呢赌场 (Classic Casino)**：传统沉稳的翡翠绿呢绒桌垫、黄铜边框与金色高光。
     - **⚡ 赛博朋克霓虹 (Cyberpunk Neon)**：未来科幻网格、电光青与荧光粉红光晕、暗黑科技全息感卡牌。
     - **🕹️ 8-Bit 复古街机 (Retro Arcade)**：80 年代蒸汽波紫色宇宙、街机像素粗边框与炫彩高饱和电玩风。
     - **☕ 温暖原木咖啡 (Cozy Cafe & Wood)**：温暖红木实木桌、羊皮纸卡牌与手冲咖啡馆温馨桌面游戏感。
     - **🌌 深邃星空秘境 (Midnight Celestial)**：浩瀚宇宙星云紫、月光铂金与神秘塔罗星芒质感。
   - 自动记忆选中的主题风格，不同设备无缝适配。

4. **📡 在线多人联机对战 (Online Multiplayer Mode)**
   - **4位房间代码**：一键创建房间或输入代码加入。
   - **一键邀请链接**：点击“🔗 复制链接”，好友点击链接直接进房。
   - **跨设备无缝联机**：支持手机、平板、电脑多端同屏实时同步。
   - **掉线自动重连**：基于 WebSocket 与会话恢复机制，刷新页面无缝回到原座位。

4. **🤖 智能 AI 机器人 (Smart AI Bots)**
   - 包含不同性格的 AI 玩家：
     - **谨慎型 (Careful Carl)**：见好就收，手牌达到安全分值即锁定停牌。
     - **均衡型 (Lucky Lucy / Strategic Sam)**：动态计算期望值与爆牌概率，理性博弈。
     - **激进型 (Risky Rick / Daring Dan)**：极限追逐大牌与 Flip 7 奖励的赌圣风格。

5. **📊 实时牌库统计与爆牌概率雷达 (Bust Odds HUD)**
   - 牌桌中央与摸牌按钮上实时显示：
     - 摸牌堆剩余张数与弃牌堆计数。
     - 牌库中与你手中重复的卡牌数量。
     - **当前摸牌的真实爆牌几率（%）**，辅助做出最佳博弈决策。

6. **🎵 Web Audio 拟真音效与视觉动效**
   - 零额外音频文件依赖，通过 Web Audio API 动态合成洗牌抽牌声、爆牌碎裂警报、护盾吸收金鸣、冰冻清脆音效及 Flip 7 胜利交响乐。
   - 支持一键静音、胜利彩带礼花粒子效果、实时漂浮表情互动（🔥, 🍀, 😱, 😂, 👏, 💀）。

## 🚀 极速启动 (Quick Start)

本项目**无需 Node.js、无需 pip 安装任何包**，仅依赖 Python 3 标准库即可运行！

### 1. 启动服务
在项目根目录运行：

```bash
python3 server.py
```

默认运行在 **8000** 端口：
```
👉 http://localhost:8000
```
*(如需自定义端口，可直接传入参数，例如：`python3 server.py 8080`)*

### 2. 参与游戏
- **本地同屏多人**：点击首页【👥 本地同屏多人对战】，配置玩家人数与姓名，即可立刻开始对局。
- **在线创建房间**：点击【✨ 创建房间】，将房间代码或邀请链接分享给好友。
- **快速单人练手**：点击【🤖 快速单人练习】，系统会自动为你匹配 3 个智能机器人立即开打。

## 🎲 Flip 7 官方卡牌构成与规则详解

### 牌库构成 (共 94 张牌)

1. **数字牌 (0–12，共 79 张)**：
   - 牌面数值等于牌库中该数字的总张数：
     - `0`：1 张（0分）
     - `1`：1 张（1分）
     - `2`：2 张（2分）
     - `3`：3 张（3分）
     - ...
     - `12`：12 张（12分）
   - *策略提示：大数字虽然分值极高，但在牌堆中张数极多，极易翻出重复牌导致爆牌！*

2. **加分卡与翻倍卡 (共 6 张)**：
   - **`+2, +4, +6, +8, +10`**（各 1 张，共 5 张）：直接为本轮手牌追加对应基础分值。
   - **`x2` 翻倍卡**（1 张）：将手中所有数字牌与加分卡的总和直接乘以 2！
   - *加分卡和翻倍卡绝不会触发爆牌。*

3. **特殊功能卡 (共 9 张)**：
   - ❤️ **第二次机会 (Second Chance, 3张)**：多一条命！获得一颗免爆爱心。当你翻出重复数字时，爱心会自动消耗并抵消这次爆牌，保住本轮性命！（若已拥有爱心又翻出一张，可将这颗爱心赠送给场上其他玩家）。
   - ❄️ **冰冻卡 (Freeze, 3张)**：指定场上任意一名进行中的玩家，强迫其立刻停牌并锁定当前手牌分数。
   - ⚡ **连翻三张 (Flip Three, 3张)**：指定一名玩家，强迫其必须连续翻开 3 张牌！

## 🧮 计分与胜利判定

每轮结束时：
- **爆牌玩家**：得 `0 分`。
- **停牌 / 达成 Flip 7 的玩家**：
  $$\text{本轮得分} = ((\text{数字牌数值和} + \text{加分卡数值和}) \times (2 \text{ 若有 } \times 2)) + (15 \text{ 若达成 Flip 7})$$
- 率先达到或超过目标分数（默认 **200 分**，可设置为 100 或 150 分）的玩家荣获总冠军！
